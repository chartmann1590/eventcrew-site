# EventCrew website

Keep your group together at concerts, festivals and other crowded events. One person starts the event in the Android app; friends join from a link in their phone's browser, with no install, and share a live map, group chat and photos. Everything is permanently deleted when the event ends.

- Website: https://eventcrew.sites.tab.bot/
- Privacy Policy: https://eventcrew.sites.tab.bot/privacy/
- Delete your data: https://eventcrew.sites.tab.bot/delete/
- Support: [open an issue](https://github.com/chartmann1590/eventcrew-site/issues/new/choose)

This repository holds the website's source (static HTML and CSS) and is the support channel for the app. Issues are public, so please don't post invite links, locations or other personal data.
